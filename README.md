# AI Recruitment & Candidate Screening System

An AI-powered recruitment platform that analyzes candidate resumes
and matches candidates with job requirements.

## Objective

The system will extract candidate skills and experience, compare
candidate profiles with job requirements, calculate suitability
scores, rank candidates, and assist recruiters during the initial
screening process.

## Current Features

- FastAPI backend setup
- REST API health check
- Project structure initialized

## Tech Stack

- Python
- FastAPI
- REST API

More technologies will be added as the project develops.

## Current Status

Project setup and basic FastAPI backend completed.
